## APA YANG KAMI MINTA (MINIMAL, TERUKUR)

### Permintaan 1: SK Walikota — Platform Resmi Kota
**Bentuk:** Surat Keputusan Walikota Surakarta
**Isi:**
- Menetapkan Ride-Solo sebagai platform transportasi digital resmi Kota Surakarta
- Mendorong OPD menggunakan Civic Dashboard Ride-Solo
- Mendorong warga menggunakan Ride-Solo untuk layanan transportasi dan civic
**Nilai investasi Pemkot:** Non-fiskal (hanya tanda tangan)
**Dampak:** Legitimasi → adopsi massal → ekosistem tumbuh

### Permintaan 2: Subsidi Karcis 3 Bulan Perdana
**Bentuk:** Anggaran APBD atau DAU/program inkubasi STP
**Nominal:** Rp 67.500.000
**Kalkulasi:** 50 driver × Rp 15.000/hari × 90 hari
**Tujuan:** Karcis gratis 3 bulan pertama untuk 50 driver perdana
**Return:** Komunitas awal yang stabil + momentum awal ekosistem

### Permintaan 3: Biaya Infrastruktur Teknis Tahun 1
**Bentuk:** Anggaran operasional STP / program digitalisasi
**Nominal:** Rp 36.000.000
**Rincian:**
- Google Maps API: Rp 36.000.000/tahun (Rp 3 juta/bulan)
- Firebase Hosting & Firestore: Sudah di-cover oleh STP
**Catatan:** Tahun ke-2 seterusnya, sudah di-cover dari pendapatan karcis

### Permintaan 4: Integrasi Wajib 5 OPD Prioritas
**Bentuk:** Instruksi Walikota / koordinasi internal OPD
**5 OPD Prioritas:**
1. **Dishub** — Perizinan angkutan, data mobilitas
2. **Dinkes** — Surat keterangan, program kesehatan
3. **DLH** — Eco-Points, laporan lingkungan
4. **Disdag** — Izin UMKM, program GPM/SPHP
5. **Diskominfo** — Aduan warga, disposisi multi-dinas
**Nilai investasi:** Non-fiskal (koordinasi internal)
**Return:** 5 OPD digital-ready + data layanan publik realtime

### Permintaan 5: SE Perlindungan Driver Koperasi
**Bentuk:** Surat Edaran Walikota
**Isi:**
- Mengakui status driver koperasi sebagai entitas kerja yang sah
- Memberikan perlindungan dari tindakan penangguhan sepihak oleh platform asing
- Mendorong asuransi dasar (BPJS Ketenagakerjaan) untuk driver koperasi
**Nilai investasi:** Non-fiskal
**Return:** 3.000+ driver Solo merasa dilindungi → loyalitas ekosistem tinggi

## APA YANG PEMKOT DAPATKAN — RINCIAN LENGKAP

### Civic Dashboard — Gratis Selamanya

```
BAPPEDA dapat:
  · Peta mobilitas warga realtime per kelurahan
  · Volume perputaran uang per pasar tradisional
  · Top layanan dinas yang paling dibutuhkan warga
  → Dasar kebijakan berbasis data, bukan asumsi

KEPALA DINAS dapat:
  · Monitor SLA responsivitas staf (wajib jawab dalam X jam)
  · Queue permohonan warga — prioritas by urgency
  · Analytics kepuasan layanan (rating warga per dinas)
  → Akuntabilitas publik yang terukur

WALIKOTA dapat:
  · Ecosystem overview: berapa driver aktif, UMKM, warga
  · Broadcast program langsung ke segmen warga tertentu
  · Early warning: dinas mana yang SLA-nya sering terlampaui
  → Instrumen monitoring pemerintahan berbasis data
```

### Instrumen Subsidi Digital — Lebih Efisien dari Konvensional

```
PROGRAM PEMKOT YANG BISA DIDIGITALISASI:

1. GPM (Gerakan Pangan Murah) × BULOG:
   → Voucher digital untuk warga → pakai di /services/pasar-murah
   → Realtime tracking: berapa yang sudah ditebus

2. Subsidi Ongkir Lansia:
   → Kode voucher khusus untuk KK dengan anggota lansia
   → Verifikasi KTP digital — tidak bisa dipalsukan

3. Karcis Subsidi Driver Berprestasi:
   → Driver dengan rating terbaik → karcis gratis bonus dari Pemkot
   → Insentif produktivitas berbasis data

4. Eco-Points × Program Lingkungan DLH:
   → Warga setorkan sampah → dapat poin → belanja di UMKM lokal
   → Program lingkungan yang punya efek ekonomi nyata
```
