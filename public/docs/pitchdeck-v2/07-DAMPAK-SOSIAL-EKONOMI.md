## DAMPAK 2: UMKM LOKAL — BERTUMBUH TANPA KOMISI

### Matemátika Baru yang Adil untuk UMKM

```
SKENARIO: Warung Nasi Liwet Solo (150 order/bulan via platform)

KONDISI DENGAN GOFOOD (Komisi 30%):
  Revenue order   : 150 × Rp 25.000 = Rp 3.750.000
  Komisi GoFood   : - Rp 1.125.000 (30%)
  Biaya packing   : - Rp 225.000
  Bahan baku      : - Rp 1.875.000 (HPP 50%)
  ─────────────────────────────────────────────
  SISA BERSIH     : Rp 525.000 (14%)

KONDISI DENGAN RIDE-SOLO (Komisi 0%):
  Revenue order   : 150 × Rp 25.000 = Rp 3.750.000
  Komisi          : Rp 0 (Zero Commission)
  Fee keanggotaan : - Rp 75.000/bln (flat)
  Biaya packing   : - Rp 225.000
  Bahan baku      : - Rp 1.875.000
  ─────────────────────────────────────────────
  SISA BERSIH     : Rp 1.575.000 (42%)
  
KENAIKAN MARGIN BERSIH: 200% (dari 14% → 42%)
PENGHEMATAN ABSOLUT per bulan: Rp 1.050.000
```

### Dampak UMKM Melampaui Finansial

| Aspek | Dampak Nyata |
|-------|-------------|
| **Flash Sale Shift** | UMKM bisa "sengaja ramai" di jam subuh/sore → food waste berkurang |
| **Data Pelanggan** | UMKM tahu siapa pelanggan setianya, preferensi, dan frekuensi kunjungan |
| **Toko Digital Gratis** | UMKM punya "toko online" tanpa biaya setup atau iklan |
| **Supply dari Industri** | Koneksi langsung ke distributor lokal untuk bahan baku lebih murah |
| **Rating & Review** | Reputasi digital yang dibangun tetap milik UMKM, tidak milik platform |

### Dampak Kolektif (200 UMKM, Tahun 3)

```
200 UMKM × Rp 1.050.000 penghematan/bln × 12 bln
= Rp 2.520.000.000/tahun
= 2,5 miliar rupiah yang sebelumnya mengalir ke komisi platform asing
  kini tetap menjadi profit UMKM Surakarta
```

## DAMPAK 3: WARGA SEBAGAI KONSUMEN

### Layanan Lebih Baik, Harga Lebih Terjangkau

| Aspek | Kondisi Saat Ini | Dengan Ride-Solo |
|-------|-----------------|-----------------|
| **Tarif ojek** | Surge pricing saat hujan/jam sibuk | Tarif flat adaptif — transparan |
| **Layanan dinas** | Antri di kantor, berulang kali datang | Digital 1 klik, tracking status |
| **Kuliner UMKM** | Harga naik karena UMKM menanggung komisi | Harga lebih terjangkau (margin UMKM sehat) |
| **Flash sale lokal** | Tidak ada insentif beli di warung lokal | Flash Sale Shift khusus UMKM lokal |
| **Program subsidi** | Tidak tahu ada program GPM/SPHP | Notifikasi langsung ke HP |
| **Laporan masalah** | Tidak tahu lapor ke mana | Multi-channel, ada audit trail |

### Eco-Points — Insentif Perilaku Lingkungan

```
Warga setorkan sampah daur ulang → Dapat Eco-Points
Eco-Points bisa ditukar:
  ↳ Diskon ongkir (kurangi pengeluaran)
  ↳ Diskon di UMKM mitra (dukung ekonomi lokal)
  ↳ Voucher pasar tradisional (jaga eksistensi pasar lokal)
  
DAMPAK GANDA:
  Lingkungan: Sampah terpilah meningkat → Surakarta lebih bersih
  Ekonomi: Uang dari insentif berputar di UMKM lokal
  Sosial: Budaya memilah sampah menjadi kebiasaan ekonomis
```

## DAMPAK 4: PEMKOT — KEDAULATAN DATA & KEBIJAKAN

### Dashboard Civic: Dari Buta Menjadi Melek Data

```
SEBELUM:
  Bappeda Surakarta: "Berapa perputaran uang di Pasar Legi minggu ini?"
  → Tidak ada data realtime. Harus survei manual.
  
DENGAN RIDE-SOLO:
  Bappeda buka Dashboard → Filter: "Pasar Legi, 7 hari terakhir"
  → Jumlah transaksi: 2.341 order
  → Volume rupiah: Rp 234.100.000
  → Produk paling dicari: Sayur & Bumbu
  → Jam puncak: 06.00–08.30 WIB
  → Segmen pembeli: 67% ibu rumah tangga, 33% pedagang
```

### Instrumen Subsidi Digital Langsung

```
SEBELUM: Subsidi beras Rp 10.000/kg untuk warga miskin
  → Distribusi manual via RT/RW
  → Potensi bocor, tidak tepat sasaran
  → Tidak ada verifikasi penerima
  
DENGAN RIDE-SOLO: Subsidi digital via voucher kode
  → Hanya warga terverifikasi KTP Solo yang bisa klaim
  → Satu KTP = satu voucher (tidak bisa dobel klaim)
  → Pemkot lihat real-time siapa yang sudah klaim
  → Sisa anggaran subsidi terhitung akurat
```
