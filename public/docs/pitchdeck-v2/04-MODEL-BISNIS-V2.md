**Prinsip Governance:**
1. **STP** bertanggung jawab atas teknologi, keamanan, dan pengembangan platform
2. **Koperasi Driver** mengelola iuran karcis, distribusi SHU, dan advokasi anggota
3. **Koperasi UMKM** mengelola standar kualitas, dispute resolution, dan program bersama
4. **Advisory Board** memastikan platform selaras dengan kebijakan kota dan kepentingan publik

## ALUR PENDAPATAN LENGKAP (Revenue Flow)

### Alur 1: Transportasi (Ojek, Mobil, Kurir, Titip)

```
CUSTOMER
  ↓ Bayar tarif trip Rp 20.000–100.000
DRIVER (terima 100%)
  ↓ Malam hari: bayar karcis Rp 0–15.000
KOPERASI DRIVER (dikelola STP)
  ↓ Akumulasi karcis bulanan
STP (Biaya Operasional)
  ↓ Sisa setelah biaya
SHU KOPERASI
  → 70% → DRIVER (akhir tahun / RAT)
  → 30% → Cadangan + Reinvestasi Platform
```

### Alur 2: UMKM (Kuliner, Pasar, Mart)

```
CUSTOMER
  ↓ Bayar harga menu + ongkir kurir
UMKM (terima harga menu 100%)
DRIVER (terima ongkir 100%)
STP
  ↓ Terima fee keanggotaan UMKM (Rp 50.000–100.000/bln)
  ↓ Bukan per-order commission
KOPERASI UMKM
  → SHU dibagi ke UMKM anggota aktif
```

### Alur 3: Industri B2B

```
INDUSTRI
  ↓ Bayar kontrak armada kargo
STP
  ↓ Kelola armada driver kargo
DRIVER KARGO (terima fee kontrak)
STP
  ↓ Terima management fee 10% dari nilai kontrak
```

### Alur 4: Government OPD

```
PEMKOT / OPD
  ↓ Bayar subscription dashboard civic (opsional)
STP
  ↓ Provide dashboard + API + support
WARGA
  ↓ Gratis menggunakan layanan civic
  ↓ Memberi data mobilitas yang valuable untuk perencanaan kota
```

## SKEMA KARCIS HARIAN — DETAIL MEKANISME

### Skala Tarif Karcis

| Waktu Online | Tarif | Rasionale |
|-------------|-------|-----------|
| 0–3 jam | Rp 5.000 | Driver sambilan, kontribusi ringan |
| 3–6 jam | Rp 9.000 | Driver reguler, standar koperasi |
| **> 6 jam** | **Rp 0 — GRATIS** | Reward aktif: driver full-time disubsidi koperasi |
| Hari libur nasional | Rp 5.000 | Reduksi khusus hari libur |
| Jam hujan deras (force majeure) | Rp 0 | Kebijakan koperasi situasional |

**Alasan Karcis Gratis untuk Driver >6 Jam:**
- Mendorong driver aktif seharian (lebih banyak trip = lebih banyak nilai ekosistem)
- Memastikan ketersediaan armada di jam sibuk (pagi & sore)
- Menciptakan loyalitas: driver tidak merasa "diperas" tapi "dihargai"

### Skema SHU — Perhitungan

```
TOTAL KARCIS TERKUMPUL (12 bln)
  - Biaya Operasional Platform
  - Cadangan Darurat Koperasi (10%)
─────────────────────────────────
SHU KOTOR KOPERASI

SHU KOTOR × 70% = BAGIAN DRIVER
SHU KOTOR × 30% = REINVESTASI + CADANGAN

BAGIAN DRIVER dibagi proporsional:
  Bobot = (Total Trip Driver / Total Trip Semua) × (Hari Aktif / Total Hari)
  
Artinya: Driver yang lebih rajin dan aktif mendapat SHU lebih besar.
Driver tidak aktif tetap mendapat SHU tapi proporsional lebih kecil.
```

## MODEL FLASH SALE UMKM — BISNIS YANG WIN-WIN-WIN

**Bagaimana Flash Sale Shift Bekerja:**

```
UMKM Set Flash Sale:
  Produk: Nasi Liwet
  Shift: Sore (16.30–19.30)
  Diskon: 25%
  Kuota: 30 porsi

CUSTOMER:
  Beli saat jam shift → dapat harga diskon
  → Dapat Poin Stamp untuk pembelian berikutnya

UMKM:
  Volume naik (30 porsi habis dalam 2 jam vs biasanya 6 jam)
  Bahan baku segar tidak terbuang (food waste turun)
  Visibilitas produk di beranda terus naik

DRIVER:
  Banyak order kuliner pada jam shift → pendapatan trip naik
  Tidak ada momen sepi (driver aktif di jam shift dapat lebih banyak trip)

STP/KOPERASI:
  Ekosistem lebih sehat → semua anggota lebih aktif
  Data demand per jam → BizEngine bisa optimasi tarif lebih akurat
```
