## OPSI PENDANAAN 3: HIBAH / PROGRAM NASIONAL

### Sumber Hibah yang Relevan

**A. Kemenkopukm — Program Digitalisasi Koperasi**
```
Program: Bantuan Pengembangan Ekosistem Digital Koperasi
Skema: Hibah 70–100% untuk pengembangan platform koperasi digital
Nilai Potensial: Rp 200.000.000–500.000.000
Persyaratan:
  ✓ Koperasi terdaftar (Koperasi Mitra Ride-Solo)
  ✓ Rencana bisnis digital yang terverifikasi
  ✓ Potensi dampak ke anggota koperasi minimal 50 orang
Proses: Proposal → Seleksi → Survey → Pencairan (3–6 bulan)
```

**B. Kemendagri — Program Inovasi Digital Daerah**
```
Program: Dana Alokasi Khusus Non-Fisik Digitalisasi Pemda
Skema: Transfer ke daerah untuk digitalisasi layanan publik
Nilai Potensial: Rp 500.000.000–2.000.000.000 (untuk yang lolos seleksi)
Persyaratan:
  ✓ Perda/SK Walikota tentang platform digital kota
  ✓ Rencana digitalisasi OPD yang terstruktur
  ✓ Sustainability plan jangka 5 tahun
Proses: Proposal ke Ditjen Otonomi Daerah → 6–12 bulan
```

**C. BAKTI Kominfo — Program Literasi Digital**
```
Program: Dukungan ekosistem digital komunitas lokal
Nilai Potensial: Rp 100.000.000–300.000.000
Fokus: Digitalisasi UMKM + komunitas driver
```

**D. LPDB-KUMKM — Pinjaman Lunak Koperasi**
```
Lembaga Pengelola Dana Bergulir Koperasi & UMKM
Skema: Pinjaman bunga rendah (4–7% per tahun) untuk koperasi
Nilai Potensial: Rp 500.000.000–2.000.000.000
Peruntukan: Modal kerja koperasi (subsidi karcis masuk kategori ini)
Kelebihan: Bukan hibah — harus dikembalikan, tapi bunga sangat rendah
```

**E. World Bank / ADB — Program Smart City**
```
Regional: Asian Development Bank Smart City Program
Nilai: USD 100.000–500.000 (Rp 1,6–8 miliar)
Persyaratan: Termasuk dalam RPJMD sebagai program Smart City
Proses: Sangat panjang (12–24 bulan), biasanya via Bappenas
Rekomendasi: Target untuk ekspansi Tahun 3–5, bukan Tahun 1
```

## REKOMENDASI: SKEMA PENDANAAN OPTIMAL

### Strategi Kombinasi (Paling Realistis & Cepat)

```
SKEMA HYBRID 3 SUMBER:

SUMBER 1 — STP Program Inkubasi (Rp 78.000.000):
  Tidak perlu persetujuan DPRD → eksekusi segera
  Cukupi: Deployment + tim + monitoring

SUMBER 2 — APBD Multi-Dinas (Rp 119.500.000):
  Koordinasi Dishub + Disdag + Diskominfo masing-masing allocate
  Ajukan dalam APBD-Perubahan atau anggaran tahun depan
  Cukupi: Karcis subsidi + pelatihan OPD + marketing

SUMBER 3 — Proposal Hibah Kemenkopukm (Rp 67.500.000+):
  Sebagai backup / complementary jika APBD belum siap
  Target: Q1 2027 (bisa retroaktif untuk reimburse karcis Q4 2026)

TOTAL DARI 3 SUMBER: Rp 265.000.000 (mendekati target penuh)
```

### Timeline Pendanaan

```
Agustus 2026:
  → STP alokasikan Rp 78.000.000 dari anggaran inkubasi
  → Mulai deployment & persiapan teknis

September 2026:
  → Pengajuan proposal hibah Kemenkopukm
  → Koordinasi multi-dinas untuk APBD-Perubahan 2026

Oktober 2026 (SOFT LAUNCH):
  → Dana STP digunakan untuk fase awal
  → 50 driver mulai bergabung dengan subsidi karcis sementara

November 2026:
  → APBD-Perubahan disetujui → dana OPD training + karcis masuk
  → Pembayaran retroaktif karcis bulan Oktober

Januari 2027:
  → Dana hibah Kemenkopukm (jika disetujui) masuk
  → Koperasi mulai akumulasi karcis sendiri → mengurangi ketergantungan dana luar

April 2027 (BEP):
  → 100+ driver aktif → Platform self-sustaining
  → Tidak ada lagi kebutuhan pendanaan eksternal untuk operasional rutin

  5.1.02.xx → Belanja Barang dan Jasa (cloud, domain)

```
