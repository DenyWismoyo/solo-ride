## METODOLOGI: APA ITU "NILAI ORGANIK"?

```
NILAI ORGANIK ≠ Nilai yang diklaim dalam pitch
NILAI ORGANIK  = Nilai yang terbentuk secara natural
                 dari penggunaan platform sehari-hari

Cara menghitungnya:
  1. Identifikasi setiap fitur yang sudah live
  2. Ukur dampak konkret ke pengguna per fitur
  3. Kuantifikasi nilai moneter (jika bisa)
  4. Identifikasi nilai non-moneter (brand, sosial, data)
```

## EKOSISTEM 5: NILAI UNTUK PEMERINTAH (Civic Layer)

### Nilai Quantifiable

| Fitur | Nilai Moneter Setara | Basis Kalkulasi |
|-------|---------------------|-----------------|
| **Dashboard Civic Realtime** | Rp 500.000.000–2.000.000.000 | Biaya pembangunan platform BPS/Bappeda sejenis |
| **Portal 19 OPD Digital** | Rp 19 × Rp 50.000.000 = Rp 950.000.000 | Biaya digitalisasi per OPD jika dikerjakan sendiri |
| **SLA Monitor & Audit Log** | Rp 200.000.000 | Biaya sistem audit trail & akuntabilitas OPD |
| **Multi-Agency Forwarding** | Rp 100.000.000 | Workflow management system OPD |
| **Emergency Dispatch System** | Rp 500.000.000 | Sistem dispatch darurat Damkar/BPBD |
| **KYC Driver Digital** | Rp 150.000.000 | Digitalisasi database driver Dishub |

**Total Nilai Platform bagi Pemkot (jika dibangun sendiri): Rp 3.400.000.000+**

### Nilai Efisiensi Operasional Pemkot

```
Dengan Portal 19 OPD Digital:
  Asumsi: Setiap dinas terima 50 permohonan/bulan via Ride-Solo
  Penghematan per permohonan: 30 menit petugas + 60 menit warga
  Total: 19 dinas × 50 permohonan × 90 menit = 85.500 menit/bln
  = 1.425 jam kerja petugas yang bisa dialihkan ke tugas prioritas
  = Setara 8 posisi staf yang tidak perlu diangkat (efisiensi)
  Nilai moneter: 8 × Rp 3.000.000/bln = Rp 24.000.000/bln = Rp 288.000.000/tahun
```

### Nilai Data Sovereignty (Tidak Ternilai)

```
Dengan Ride-Solo dikelola STP (lembaga Pemkot):
  ✦ Data mobilitas 150.000 warga Solo ada di server lokal
  ✦ Data transaksi ekonomi 44 pasar ada di kendali Pemkot
  ✦ Data permohonan 19 OPD tidak bocor ke pihak asing
  ✦ Data driver (KTP, SIM, GPS) aman dari eksploitasi platform asing
  
  Jika platform ini dikelola Gojek/Grab:
  → Semua data ini mengalir ke server luar negeri
  → Pemkot tidak punya akses, tidak punya kontrol
  
  Nilai Data Sovereignty: Tidak bisa dikuantifikasi dalam rupiah,
  tapi setara dengan kedaulatan digital Kota Surakarta.
```
