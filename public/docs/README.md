## 🎯 Filosofi Dokumen Ini

Semua dokumen di folder ini adalah **sumber kebenaran publik** untuk:
- Investor yang ingin memahami model bisnis
- Mitra (driver, UMKM, industri) yang ingin bergabung
- Pemda Surakarta yang mengevaluasi program kolaborasi
- Developer yang membangun fitur di atas ekosistem ini
