## 🎯 Panduan Penggunaan Dokumen

### Untuk Paparan 30 Menit (Briefing Singkat Walikota)
```
Halaman 1: Executive Summary (00-EXECUTIVE-SUMMARY.md)
Halaman 2: Masalah + Solusi (01-PITCH-DECK-UTAMA.md, Bab 2–3)
Halaman 3: Proyeksi + ROI (01-PITCH-DECK-UTAMA.md, Bab 7)
Halaman 4: Yang Diminta + Yang Didapat (01-PITCH-DECK-UTAMA.md, Bab 10)
```

### Untuk Paparan 60 Menit (Forum Lengkap SKPD)
```
Semua dokumen dibaca berurutan 00 → 01 → 02 → 03 → 04 → 05
Diskusi setelah setiap dokumen
Q&A di akhir
```

### Untuk Diskusi Teknis (Tim IT Dinas)
```
Fokus pada: 01-PITCH-DECK-UTAMA.md (Bab 5: STP)
            05-GAMBARAN-EKOSISTEM.md (Arsitektur teknis)
            03-MITIGASI-RISIKO.md (R-04: Kegagalan Teknis)
```

### Untuk Diskusi Keuangan (BPKD / Bappeda)
```
Fokus pada: 01-PITCH-DECK-UTAMA.md (Bab 5, 6, 7)
            02-PROYEKSI-1-5-TAHUN.md (semua skenario)
            04-REKOMENDASI-KEBIJAKAN.md (Rekomendasi 2: Anggaran)
```
